Botão de ação, em cinco variantes de cor mais uma versão de destaque para o cabeçalho. Use `rotulo-botao` (Open Sans ExtraBold, caixa alta) como texto, `raio-md` como raio e `gap-botoes` (10px) entre botões em grupo.

Variantes: `btn-azul` (fundo `azul-techblues`, texto `branco`) para a ação primária; `btn-branco` (fundo `branco`, borda e texto `azul-techblues`) para ação secundária sobre fundo colorido; `btn-cinza` (fundo `cinza-claro-techblues`, texto `cinza-escuro-techblues`) para ação neutra/desabilitada; `btn-laranja` (fundo `laranja`, texto `cinza-max`) para CTA de destaque; `btn-laranja-hover` (fundo `amarelo-hover`, texto `cinza-max`) como estado hover do CTA. O botão de destaque do cabeçalho ("APROVEITE SUA CONSULTORIA GRÁTIS!") é a mesma variante laranja/hover, só que maior (altura 52px, texto 15px) e com o rótulo por extenso em vez de "BOTÃO".

Nunca use texto branco sobre `laranja` (contraste 2.11:1); use `cinza-max`.
